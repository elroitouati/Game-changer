# Game Changer 🛡️

אפליקציית אנדרואיד שעוזרת להתרחק מתוכן לא צנוע. היא רואה את המסך כל הזמן, ממש כמו "מצלמה פנימית", וחוסמת ברגע שמופיע עירום, פורנו, חיפוש או אתר בעייתי.
**הכל קורה בתוך הטלפון.** שום תמונה לא נשמרת ושום דבר לא נשלח לאינטרנט.

## הורדה
**[⬇️ הורד את GameChanger.apk](https://github.com/elroitouati/game-changer/releases/latest/download/GameChanger.apk)**

אחרי ההתקנה, עדכונים מופיעים בתוך האפליקציה עם כפתור "עדכן עכשיו".

## מגבלות (בכנות)
- **נטפליקס, דיסני+, yes, HOT** חוסמות טכנית צילום מסך, ולכן המגן לא רואה את הווידאו שם. בהן כדאי להשתמש בפרופיל עם הגבלת גיל.
- **אינקוגניטו** נחסם, כי אי אפשר לבדוק בו תמונות.
- אי אפשר לחסום "לפני" שמשהו מופיע. החסימה קורה תוך חלקיק שנייה מרגע ההופעה.
- אף מודל לא מושלם. יהיו פספוסים ויהיו חסימות מיותרות.
- דרוש אנדרואיד 11 ומעלה.

## פיתוח
```bash
./scripts/fetch-model.sh      # מוריד את המודל (NudeNet 320n, רישיון AGPL-3.0)
./gradlew assembleRelease
```
**חתימה:** כדי שעדכונים יותקנו מעל הגרסה הקודמת, כל הגרסאות נחתמות באותו מפתח. המפתח לא נמצא בריפו (הוא ציבורי), אלא ב-GitHub Secrets:
`SIGNING_KEYSTORE_BASE64` (קובץ ה-keystore בבסיס64) ו-`SIGNING_PASSWORD`.

כל push בונה APK ומפרסם Release חדש (`v<מספר בנייה>`). ה-Release הזה הוא מה שהעדכון בתוך האפליקציה מוריד.
